以下文件已经完成翻译：

- [index.md](./index.md) - Joplin 介绍

- `apps/` - 应用相关文档（各平台客户端、Web Clipper等）
- `dev/` - 开发者文档和技术指南

## 翻译原则

1. 保持专业术语的准确性
2. 适应中文用户的阅读习惯
3. 保留原文的链接和引用
4. 保持格式与原文一致
