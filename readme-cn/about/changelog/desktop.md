# Joplin桌面应用更新日志

## [v2.14.19](https://github.com/laurent22/joplin/releases/tag/v2.14.19) （预发布） - 2024-05-01

- 改进：确保集成应用在重新尝试之间没有内存泄漏
- 改进：更快地创建笔记，特别是与OneNote
- 修复：如果URL包含片段，将链接转换为笔记时会出错 (#9713)
- 修复：固定了命令框无法显示网络文件夹中的项目的问题
- 修复：修复了导入大量笔记时可能的内存限制错误
- 修复：笔记统计功能对某些文本以错误方式计数 (#9611)
- 修复：小写化插件无法在2.14.18中正常工作 (#9709 #9717)
- 修复：在WSL上同步目录不允许修改 (#9652)
- 修复：macOS下Joplin菜单项不正常工作 (#9701 #9702)
- 修复：修复了某些URL中可能存在安全问题 (CVE-2024-32473)
- 修复：修复了插件可能在安装后触发一些隐藏功能的问题 (CVE-2024-34144) (感谢PsiHD3)
- 安全：更新插件打包安全依赖 (#9703)
- API：修复joplin.workspace.filterEditorContextMenu hook (#9668)
