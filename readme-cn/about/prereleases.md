# 获取预发布版本

预发布版本可用于[桌面版](https://github.com/laurent22/joplin/releases)、[Android版](https://github.com/laurent22/joplin-android/tags)和[iOS版](https://testflight.apple.com/join/p5iLVzrG)。它们与常规版本基本相同，只是尚未经过大量用户测试，因此可能会有一两个bug未被发现。

您可以通过在更新应用程序时选择接收这些早期版本来帮助Joplin的开发。如果您发现任何bug或其他问题，请在[GitHub](https://github.com/laurent22/joplin/issues)或论坛上报告（如果您没有GitHub账户）。在预发布阶段的任何bug报告对我们都是无价的，因为它使我们能够在向所有人提供应用程序之前使其更加可靠。

通常使用这些预发布版本是安全的，因为它们不包含任何实验性或不稳定的功能。数百名用户运行它们而没有任何问题。此外，即使您确实发现问题，也可以报告它，并且通常会很快修复，因为这些bug被赋予最高优先级。

要访问这些预发布版本，只需前往[配置 &gt; 应用程序](https://github.com/laurent22/joplin/blob/dev/readme/apps/config_screen.md)并勾选"**检查更新时获取预发布版本**"的选项。
