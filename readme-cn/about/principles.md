# Joplin指导原则

我们的指导原则是我们做出每个决定的核心。它们定义了我们如何工作以及我们追求的目标。

## 选择自由

我们相信软件应该赋予您选择符合您需求和价值观的技术的能力。您应该能够探索各种选择，修改软件，并与他人协作。这种自由确保了透明度、隐私和安全性，使您能够按照自己的条件塑造数字体验。

在Joplin，我们通过提供多种提供商的数据同步，通过带有插件和公共API的可定制应用程序，以及使用开放技术来实现这一点。此外，我们坚定地承诺将我们的大部分软件作为开源发布，并积极参与开源社区。

我们还提供多种导入和导出选项。最终，我们希望您留在我们这里是因为您喜欢这个应用程序，而不是因为供应商锁定！

## 数据隐私

我们相信数据隐私是软件开发的关键部分。它确保您的个人信息保持安全，远离未经授权的访问。通过保护您的隐私，您可以控制您的数据如何被收集、使用和共享。隐私还保护您的民主权利，让您可以在不受干扰的情况下行使自由。在这个互联互通的世界中，数据隐私至关重要。

在Joplin，我们通过提供诸如端到端加密之类的技术来实现这一点，以确保即使数据上传到云端，也只有您自己能够访问您的数据。我们还公开我们的应用程序正在进行的网络请求，定期审查它们，并在可能的情况下提供禁用它们的方法。

## 出色的可用性

我们的核心是致力于开发优先考虑用户友好性和直观设计的软件。我们坚信，无论专业水平如何，技术都应该对所有人开放。

然而，我们对简单性的承诺并不意味着我们忽视高级用户的需求。事实上，我们通过在软件中整合一系列高级功能来满足他们的需求。这些功能提供了额外的功能和自定义选项，使有经验的用户能够突破界限并释放我们软件的全部潜力。

我们的目标是在简单性和深度之间取得平衡，确保我们的软件满足跨专业水平用户的多样化需求。

## 可靠性

在Joplin，我们了解个人笔记的重要性以及它们所包含的宝贵信息，这些信息通常需要长期保存。这就是为什么我们优先考虑应用程序的性能和可靠性。

我们通过进行严格的测试（超过3500个自动化测试）来确保最佳功能。我们还不断审查和升级我们使用的技术，适应不断变化的需求。此外，我们与安全研究人员紧密合作，他们帮助我们识别和解决潜在的漏洞，增强软件的安全性。

此外，我们重视开放访问。我们应用程序中存储的数据以开放格式存储，使您能够在不使用我们的应用程序的情况下访问和检索信息。这种对开放格式的承诺确保您的数据保持可访问性，并为您提供按照自己的意愿与笔记交互的自由。

## 可持续性

软件中的可持续性包括各种做法，旨在减少软件整个生命周期中对环境的影响。通过优先考虑可持续性，我们可以在减轻环境足迹和促进更可持续的未来方面发挥重要作用。

在Joplin，我们通过高效编码、优化和资源管理来实现这一点，以帮助最小化能源消耗和碳排放。我们还与非营利组织carbone.eco合作，并投资于在法国重新造林四公顷的森林。
