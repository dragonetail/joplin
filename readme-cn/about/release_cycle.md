# Joplin发布周期

我们每年发布三个主要版本，遵循三个阶段的过程："发布"、"冻结"和"出版"。这种可靠的时间表赋能社区，以及企业和开发者，有效地规划他们自己的路线图。

以下是每个阶段的内容：

**阶段1："发布" - 周期开始** 在这个阶段，我们的团队将专注于为下一个版本开发新功能和改进。

**阶段2："冻结" - 稳定性和错误修复** "冻结"阶段将在预定出版日期前两周开始。此时，我们将停止添加新功能，并专注于稳定软件。我们的主要目标将是修复任何剩余的错误并优化性能。

**阶段3："出版" - 最终版本** "出版"阶段是我们正式发布Joplin新版本的时候。
