# Joplin 3.2 的新功能

## 导入 OneNote 存档

Joplin 现在支持导入 OneNote 存档，这对从 OneNote 转移的用户来说是一个重要的进步。长期以来，微软通过提供有限的导出选项和复杂的格式，使得离开 OneNote 变得困难，也使应用程序开发者难以支持它。尽管面临这些障碍，@pedr 直面这些问题，开发了一个简化流程的导入工具。这一新增功能使 Joplin 成为那些想要离开 OneNote 生态系统的用户的实用选择。

要使用此功能，请选择**文件** => **导入** => **ZIP - OneNote 笔记本**

## 多窗口支持

我们很高兴地推出多窗口支持，这是一个备受期待的功能，使管理多个笔记比以往更加容易。通过此更新，您可以在不同的窗口中打开笔记，每个窗口都可以独立操作，使您能够比较笔记、参考内容和更灵活地组织项目。

要使用此功能，右键单击笔记，选择**打开方式...**，然后选择**在新窗口中编辑**

![](https://raw.githubusercontent.com/laurent22/joplin/dev/Assets/WebsiteAssets/images/news/20250114-multi-window.png)

## 移动端可自定义工具栏

移动端的新可自定义工具栏现在可以拖动，让您更容易访问所需的按钮。您还可以通过点击齿轮按钮来选择要显示哪些按钮，从而获得更加个性化和高效的笔记编辑体验！

![](https://raw.githubusercontent.com/laurent22/joplin/dev/Assets/WebsiteAssets/images/news/20250114-mobile-toolbar.png)

## 增强的无障碍功能

为了实现 [WCAG 2.0 指南](https://www.w3.org/TR/WCAG20/)，在 @personalizedrefrigerator 的努力下，无障碍功能得到了显著提升。桌面和移动应用程序现在提供更好的键盘导航，包括在下拉菜单和设置中改进的功能。焦点指示器已经变得更加可见，同时添加了 ARIA 标签以提高与屏幕阅读器的兼容性。笔记附件、侧边栏和对话框等特定区域也经过了优化，以确保所有用户都能使用。

## 改进的绘图和 Markdown 编辑

Joplin 的绘图和编辑功能已经过精细调整，提供更流畅的体验。移动端和桌面端的手绘功能已更新至 2.14.0 版本，解决了多个可用性问题和错误。此外，手绘插件现在默认成为桌面应用程序的一部分。这些变更增强了绘图工具的可靠性和集成度。

## 更快速和更安全的加密

在 GSoC 2024 项目中，@wh201906 致力于优化加密和解密过程，特别是提高了移动设备的速度（桌面版也有提升）。此外，通过过渡到更强大的 256 位密钥，加密安全性也得到了提高。

目前，此功能是可选的，可以通过进入**配置屏幕**，然后选择**同步** => **高级选项** => **使用测试版加密**来启用。

## 扩展的插件支持

开发者将会欣赏 Joplin 插件生态系统的更新。引入了一个新的 API 用于创建 [toast 通知](https://joplinapp.org/api/references/plugin_api/classes/joplinviewsdialogs.html#showtoast)，同时更新了 CodeMirror 包。还引入了一个新的 [`renderMarkup`](https://github.com/laurent22/joplin/blob/5ee8a9a45493683c72a36b52e1460b5acdd4f1ac/packages/lib/commands/renderMarkup.ts#L23) 命令，允许您使用 Joplin 内置 API 将 Markdown 内容渲染为 HTML。
