# Joplin 3.0 的新功能

## 桌面应用

### 回收站文件夹

Joplin 现在支持回收站文件夹 - 任何已删除的笔记或笔记本都将被移动到该文件夹。您还可以选择在指定天数后永久删除这些笔记。

![](https://raw.githubusercontent.com/laurent22/joplin/dev/Assets/WebsiteAssets/images/news/20240701-trash.png)

在 Joplin 中，对回收站文件夹的支持有着相当长的历史，因为这是一个明显且重要的功能，但一旦您开始意识到它会影响应用程序的多少部分，就会发现它特别棘手。

多年来我们进行了多次尝试：我的第一次尝试是基于笔记历史功能。由于该功能已经保存了笔记的版本，因此将其用于回收站功能似乎很合理，实际上笔记历史功能[最初就是为此设计的](https://joplinapp.org/news/20190523-221026)。然而，这种方法变得不必要地复杂，在仅为此修改了数百个文件后，这个想法被放弃了。

下一个方法是使用[特殊的"回收站"标签](https://github.com/laurent22/joplin/issues/483) - 已删除的笔记会附加此标签，并出现在特殊的"回收站"文件夹中。这种方法也有[许多问题](https://github.com/laurent22/joplin/issues/483)，可能最主要的一个是笔记本不能被标记，这意味着我们必须添加对标记笔记本的支持，而这本身也将是一个巨大的变化。

[各种](https://discourse.joplinapp.org/t/trashcan/3998/16)[想法](https://discourse.joplinapp.org/t/poll-trash-bin-plugin/19951)也通过插件进行了尝试，通过创建一个特殊的"回收站文件夹"，但最终没有创建出这样的插件，可能是由于插件 API 的限制。

最终，事实证明这个[旧想法](https://github.com/laurent22/joplin/issues/483#issuecomment-585655742)，即为每个笔记和笔记本添加一个"已删除"属性，是最简单的方法。通过这种方式，相对快速地得到一个可行的解决方案变得更简单，然后要做的就是确保已删除的笔记不会出现在不应该出现的地方，比如搜索结果等。

### Joplin Cloud 多因素认证

多因素认证(MFA)，也称为双因素认证(2FA)，是一种安全流程，要求您提供两个或更多验证因素才能访问系统或账户。它通常包括您知道的东西(密码)、您拥有的东西(安全令牌)以及您本人的特征(生物识别验证)。

为了更好地保护您的账户，Joplin Cloud 和所有 Joplin 应用程序现在支持 MFA。要启用它，请转到您的 Joplin Cloud 配置文件，点击"启用多因素认证"并按照说明操作。请注意，之后您的所有应用程序将断开连接，因此您需要重新登录(当然，您的数据将保留在应用程序中，因此您无需再次下载)。

![](https://raw.githubusercontent.com/laurent22/joplin/dev/Assets/WebsiteAssets/images/news/20240701-mfa.png)

### 多列笔记列表

在此版本中，我们添加了对笔记列表中多列的支持。您可以显示笔记的各种属性，以及按这些属性对笔记进行排序。像往常一样，插件可以控制和自定义此功能，例如，应该可以显示自定义列，并显示自定义信息，包括缩略图。

![](https://raw.githubusercontent.com/laurent22/joplin/dev/Assets/WebsiteAssets/images/news/20240701-note-list-multi.png)

### 插件 API 增强

插件 API 已经收到了几项更新，以促进应用程序的轻松自定义。如上所述，现在可以自定义新的笔记列表。除此之外，我们还添加了对加载 PDF 和从中创建图像的支持，例如可用于创建缩略图。

插件 API 还进行了许多其他小的改进，以帮助您根据需要定制应用程序！

### 查看 OCR 数据

现在，当您右键单击图像或 PDF 时，您可以选择查看与之关联的 OCR（光学字符识别）数据。例如，这将使您能够轻松复制和粘贴文本。

![](https://raw.githubusercontent.com/laurent22/joplin/dev/Assets/WebsiteAssets/images/news/20240701-ocr-data.png)

## 移动端插件支持

如往常一样，上述大多数更改也适用于移动端（iOS 和 Android），例如回收站文件夹和 MFA 支持。

此外，移动应用程序现在添加了对插件的支持。要启用该功能，请转到设置，然后转到"插件"部分。该功能目前处于测试阶段，特别是这意味着某些插件不起作用或仅部分工作。通常情况下，应用程序不应该提供安装不工作的插件，但这种情况仍可能发生。总的来说，如果您注意到这个测试功能有任何问题，请告诉我们，因为我们热衷于改进它。

Joplin 中对跨平台插件的支持是个好消息，因为这意味着许多新功能在移动端也变得可用。截至目前，我们已经检查了以下插件，并确认它们在移动端可以正常工作：

- [快速链接](https://joplinapp.org/plugins/plugin/com.whatever.quick-links/)
- [内联标签](https://joplinapp.org/plugins/plugin/com.whatever.inline-tags/)
- [CodeMirror 6 设置](https://joplinapp.org/plugins/plugin/io.github.personalizedrefrigerator.codemirror6-settings/)
- [函数绘图](https://joplinapp.org/plugins/plugin/com.hieuthi.joplin.function-plot/)
- [空格缩进器](https://joplinapp.org/plugins/plugin/joplin.plugin.space-indenter/)
- [内联标签导航器](https://joplinapp.org/plugins/plugin/joplin.plugin.alondmnt.tag-navigator/)

这些只是一些例子 - 还有更多插件也能正常工作！
