# 支持 Joplin 开发

Joplin 是一个开源项目，您的捐赠支持[开发者](https://github.com/laurent22/)。开发高质量的应用程序主要需要时间，但也有费用，例如签署应用程序的数字证书、应用商店费用、托管，以及开发和测试跨平台应用程序的硬件。

最重要的是，您的捐赠将使维持当前的开发标准成为可能，并为应用程序带来新功能和改进。

## 支持开发的其他方式

此外，还有其他方式支持 Joplin 的开发：
