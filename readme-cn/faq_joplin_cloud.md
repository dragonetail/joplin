# 常见问题

## 什么是 Joplin Cloud？

[Joplin Cloud](https://joplincloud.com) 允许您自动将笔记同步到所有设备。此外，该服务还提供以下额外功能：

- 将笔记发布到互联网并与他人共享。每当您进行更改时，已发布的笔记将自动更新。

- 与其他 Joplin Cloud 用户协作处理笔记本。您可以与其他用户共享笔记本，他们将拥有对其的完全访问权限 - 他们可以阅读、更改或向笔记本添加更多笔记、图像或文档。这对于与他人一起构思想法或处理项目非常方便。

- 提升同步性能。与其他同步选项相比，专为 Joplin 开发的 Joplin Cloud 更快且消耗更少的资源。

- 将电子邮件转发到您自己的 Joplin 收件箱地址，创建笔记，帮助您存储和查找所有对您重要的信息。

此外，通过获取订阅，您支持了整个项目的开发，包括开源应用程序。这种支持在长期内是必要的，用于提供错误和安全修复、添加新功能以及提供支持。

## 您是否提供折扣？

我们为学生和教师提供 50% 的教育折扣。要申请此折扣，请使用您的大学或学校电子邮件地址与我们联系。然后您将收到一个 URL，可以使用该 URL 订阅 Joplin Cloud，同时享受 50% 的折扣。这在一整年内有效，只要您仍在接受教育，可以再次联系我们进行续订。

我们还可能为公司、协会和非营利组织提供批量折扣。请[联系我们](https://raw.githubusercontent.com/laurent22/joplin/dev/Assets/Aide.png)获取更多详情。

## Joplin Cloud 数据存储在哪里？

Joplin Cloud 的数据和服务器都位于法国（巴黎），因此您的数据受益于包括 GDPR 在内的强大数据保护法规。
