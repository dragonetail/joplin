# 本地化

## 翻译应用程序

Joplin目前提供以下语言版本。如果您想贡献**新的翻译**，操作相当简单，请按照以下步骤进行：

- [下载Poedit](https://poedit.net/)，这是一个翻译编辑器，并安装它。
- [下载需要翻译的文件](https://raw.githubusercontent.com/laurent22/joplin/dev/packages/tools/locales/joplin.pot)。
- 在Poedit中，打开这个.pot文件，进入"目录"菜单，点击"配置"。将"国家"和"语言"更改为您自己的国家和语言。
- 然后您就可以翻译该文件了。
- 完成后，请[创建一个拉取请求](https://github.com/laurent22/joplin/pulls)并将文件添加到其中。

这个翻译将适用于三个应用程序 - 桌面版、移动版和终端版。

要**更新翻译**，请按照上述相同的步骤操作，但不要获取.pot文件，而是从下表中获取您语言的.po文件。

## 翻译文档

Joplin文档的翻译通过[我们在Crowdin上的项目](https://crowdin.com/project/joplin-website)进行管理。要参与，只需创建一个Crowdin账户并开始翻译。

如果您想添加新语言或有任何其他问题，请[在论坛上](https://discourse.joplinapp.org/)或GitHub上联系我们。
