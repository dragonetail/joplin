# 使用 Joplin

在日常使用中，您通常会创建一个带有主题名称的笔记本（例如"食谱"、"bug"或"度假照片"），然后向这些笔记本添加任意长度的单独笔记。但在首次使用时，有几件事情需要做，以充分利用 Joplin。如果您之前使用过其他笔记应用程序，并希望将这些笔记迁移到 Joplin，那么您必须首先从之前的应用程序导出笔记，然后导入到 Joplin 中（参见[导入和导出](https://github.com/laurent22/joplin/blob/dev/readme/apps/import_export.md)）。

现在您在一台计算机或设备上有了一系列笔记；也就是说，所有笔记都存储在本地，而不是"在云端"。为了在多个设备之间共享笔记，您需要将第一个设备与某个云服务提供商同步（有关支持的云服务提供商，请参见[同步](https://github.com/laurent22/joplin/blob/dev/readme/apps/sync/index.md)）。这将把您所有的笔记上传到云端。然后，您可以在任意数量的其他设备上安装 Joplin，同步到相同的提供商，之后您所有的笔记都会下载到每个设备上。首次完成所有同步后，今后当您在一个设备上编辑笔记时，它将在几分钟内自动与所有其他设备同步。

**重要提示：** 确保在任何其他设备上设置同步之前，所有数据已通过同步从初始设备上传完毕。否则，您最初将无法看到所有数据。因此，在侧边栏（左侧）监控您的同步进度，直到显示完成；只有在那时，您才应该在其他设备上开始同步。
