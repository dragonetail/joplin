# 关于富文本编辑器

**简而言之：** 如果您主要打算使用富文本编辑器，请避免使用Markdown插件，并了解编辑器的局限性。

在核心上，Joplin以[Markdown格式](https://github.com/laurent22/joplin/blob/dev/readme/apps/markdown.md)存储笔记。Markdown是一种简单的文本格式化方式，在任何设备上都看起来很棒，虽然它是格式化文本，但在纯文本编辑器中仍然完全可读。

然而，在某些情况下，出现在笔记中的额外标记格式可能被视为缺点。例如，粗体文本将`看起来**像这样**`，而表格可能不是特别易读。因此，Joplin还提供了富文本编辑器，允许您通过[所见即所得](https://en.wikipedia.org/wiki/WYSIWYG)的编辑体验来编辑笔记。粗体文本将"看起来**像这样**"，表格也会更易读，等等。

## 局限性

但是**有一个问题**：在Joplin中，即使使用富文本编辑器编辑的笔记，在底层仍然是**Markdown**。这通常是一件好事，因为这意味着您可以随时在Markdown和富文本编辑器之间切换，而笔记仍然可读。如果您与没有富文本编辑器的移动应用程序同步，这也是好事。问题是，由于底层使用的是Markdown，这意味着富文本编辑器有许多从该格式继承的限制：

- 首先，**大多数Markdown插件将不兼容**。如果您在富文本编辑器中打开使用这类插件的Markdown笔记，很可能会丢失插件的特殊格式。唯一支持的插件是"围栏"插件 - 那些将一段文本包裹在三个反引号中的插件（例如，KaTeX、Mermaid等可以工作）。您可以在Markdown配置屏幕上查看插件的兼容性。

- 表格必须有标题，因为这是Markdown的要求。当您创建表格时，它会让您创建没有标题的表格，但在底层会添加一个空标题。下次打开笔记时，这个空标题将会存在。

- 列表中的所有项目必须是同一类型，例如全部是复选框或全部是项目符号。如果您需要两种不同的类型，应该创建两个由水平线或类似内容分隔的不同列表。

- 不支持特殊键盘模式"vim"和"emacs"。

- 如果笔记是'Markup - Markdown'类型并包含HTML格式，这可能会在富文本编辑器中编辑时丢失，因为它不能转换为Markdown。'Markup - HTML'类型的笔记不受富文本编辑器编辑的影响，因为不会发生这种转换。

- 当Joplin保存来自富文本编辑器的更改时，所有引用链接(`[标题][链接名称]`)都会转换为内联链接(`[标题](https://example.com)`)。

这些是已知的限制，但如果您注意到此处未列出的任何其他问题，请在[论坛](https://discourse.joplinapp.org/)上告诉我们。

## 标记自动完成

默认情况下，富文本编辑器会自动将某些文本模式替换为格式化内容。替换在每种模式输入后应用。

默认情况下，以下模式会被替换：

- `**粗体**`：将`粗体`格式化为**粗体**。
- `*斜体*`：将`斜体`格式化为*斜体*。
- `==高亮==`：高亮显示`高亮`。
- <code>`代码`</code>：将`代码`格式化为内联代码。
- `$数学公式$`：自动格式化为内联数学公式（使用KaTeX数学语法）。渲染后，可以通过双击或右键菜单中的"编辑"选项编辑方程式。
- `# 标题1`：创建一级标题。`#`应该在行的开头。
- `## 标题2`：创建二级标题。
- `## 标题3`：创建三级标题。
- `- 列表`：创建项目符号列表。
- `1. 列表`：创建编号列表。

大多数替换需要在结束格式字符后按<kbd>空格</kbd>或<kbd>回车</kbd>键。例如，输入`==测试==`不会高亮显示"测试"，但在最后一个`=`后按空格键则会。

可以在设置 &gt; 笔记中，使用"自动格式化Markdown"设置禁用这些替换。
