# 端到端加密 (E2EE)

Joplin 在所有应用程序上都支持端到端加密 (E2EE)。端到端加密 (E2EE) 是一种系统，只有数据（即笔记、笔记本、标签或资源）的所有者才能读取它。它能防止潜在的窃听者 - 包括电信提供商、互联网提供商，甚至 Joplin 的开发者能够访问数据。

该系统旨在抵御任何监视或篡改的企图，因为没有第三方能够解密被传输或存储的数据。

使用 E2EE 会有一点性能开销，因为数据需要不断地加密和解密，所以请考虑您是否真的需要此功能。

## 启用 E2EE

由于 Joplin 的去中心化特性，E2EE 需要首先在单个设备上手动启用（这将创建一个受您密码保护的主密钥），然后必须与所有其他设备同步。建议从桌面或终端应用程序开始，因为它们通常运行在更强大的设备上（与移动应用程序不同），因此可以更快地加密初始数据。

要启用它，请按照以下步骤操作：

1. 在您的第一个设备上（例如在桌面应用程序上），进入加密[配置界面](https://github.com/laurent22/joplin/blob/dev/readme/apps/config_screen.md)并点击"启用加密"
2. 输入您的密码。这是主密钥密码，将用于加密您的所有笔记。确保您不会忘记它，因为出于安全原因，它无法恢复。
3. 现在您需要同步所有笔记，以便将它们加密发送到同步目标（例如 OneDrive、Nextcloud 等）。等待任何可能正在进行的同步，然后点击"同步"。
4. 等待此同步操作完成。由于所有数据都需要重新发送（加密）到同步目标，这可能需要很长时间，特别是如果您有很多笔记和资源。请注意，即使同步似乎卡住了，很可能它仍在运行 - 不要取消它，如果需要，可以让它整晚运行。
5. 一旦第一次同步操作完成，打开您正在同步的下一个设备。点击"同步"并等待同步操作完成。该设备将接收主密钥，您需要提供密码。此时，E2EE 将在此设备上自动启用。完成后，再次点击同步并等待其完成。
6. 对每个设备重复步骤 5。

不要在多个设备上并行手动启用加密，而是等待其他设备与第一个已加密设备同步。否则，您可能会得到多个加密密钥（Joplin 支持这一点，但很可能不是您想要的）。

一旦所有设备都已启用 E2EE 并同步，加密/解密应该大部分是透明的。偶尔您可能会看到加密的项目，但它们最终会在后台被解密。

## 禁用 E2EE

按照上述相同的步骤操作，但每次在每个设备上一个接一个地禁用 E2EE。同样，每次可能更简单的做法是一次处理一个设备，并每次等待同步完成。
