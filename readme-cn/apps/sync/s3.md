# S3同步

从Joplin 2.x.x版本开始，Joplin支持多个S3提供商。我们提供了一些选项，需要根据您选择的提供商进行配置。以下是已测试并确认可用的提供商。

在**桌面应用程序**或**移动应用程序**中，在[配置屏幕](https://github.com/laurent22/joplin/blob/dev/readme/apps/config_screen.md)中选择"S3 (Beta)"作为同步目标。

- **S3存储桶：** 您的存储桶名称，例如`joplin-bucket`
- **S3 URL：** 完全限定URL；对于AWS，应该是`https://s3.<regionName>.amazonaws.com/`
- **S3访问密钥和S3密钥：** 用户的程序访问密钥。要在AWS上创建新的密钥和密钥，请访问[IAM安全凭证](https://console.aws.amazon.com/iam/home#/security_credentials)。对于其他提供商，请按照其文档操作。
- **S3区域：** 某些提供商要求您提供存储桶的区域。这通常是"eu-west1"或类似的形式，具体取决于您的区域。对于不需要区域的提供商，可以将其留空。
- **强制路径样式**：此设置使Joplin能够使用较旧的S3路径样式与S3提供商通信。根据您的提供商，您可能需要尝试打开和关闭此选项。

在为Joplin创建新存储桶时，禁用**存储桶版本控制**，启用**阻止所有公共访问**并使用`Amazon S3密钥(SSE-S3)`启用**默认加密**。某些提供商不提供这些选项，这可能会造成同步问题。请尝试并反馈，以便我们适当更新文档。

要从AWS S3 Web控制台添加**存储桶策略**，请导航到**权限**选项卡。暂时禁用**阻止所有公共访问**以编辑存储桶策略，类似以下内容：
```
{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Sid": "VisualEditor0",
            "Effect": "Allow",
            "Action": [
                  "s3:ListBucket",
                  "s3:GetBucketLocation",
                  "s3:GetObject",
                  "s3:DeleteObject",
                  "s3:DeleteObjectVersion",
                  "s3:PutObject"
            ],
            "Resource": [
                "arn:aws:s3:::joplin-bucket",
                "arn:aws:s3:::joplin-bucket/*"
            ]
        }
    ]
}
```

## 已测试提供商的配置设置

所有提供商都需要存储桶、访问密钥和密钥。

如果您提供配置并在"检查配置"时收到"成功！"，那么您的S3同步应该适用于您的提供商。如果您没有收到成功消息，您可能需要调整设置，或保存它们，重新启动应用程序，并尝试同步。这可能会显示更清晰的错误消息，帮助您推断问题所在。

## AWS
- URL: `https://s3.<region>.amazonaws.com/`（填入您的区域，完整的端点地址列表可以在[这里](https://docs.aws.amazon.com/general/latest/gr/s3.html)找到）
- 区域：必填
- 强制路径样式：不选中

## Backblaze
- URL: `https://s3.<region>.backblazeb2.com`（这是Backblaze B2提供的端点URL）
- 区域：必填（从提供的端点URL复制。例如：`us-east-001`）
- 强制路径样式：不选中

## DigitalOcean
- URL: `https://<region>.digitaloceanspaces.com`（区域在创建存储桶时选择，可用区域列表[在这里](https://docs.digitalocean.com/products/spaces/details/availability/)）
- 区域：必填，但对实际区域没有影响，因为它在URL中定义。建议输入`us-east-1`。
- 强制路径样式：不选中

## Linode
- URL: `https://<region>.linodeobjects.com`（区域在Linode提供的URL中；此URL与Linode提供的URL相同，但删除了存储桶名称）
- 区域：您想输入的任何内容，不能留空
- 强制路径样式：不选中

## Scaleway
- URL: `https://s3.<region>.scw.cloud`（区域与存储桶的区域相同。您可以在存储桶设置选项卡中复制存储桶端点，然后从中删除存储桶名称。）
- 区域：必填（例如：`fr-par`）
- 强制路径样式：不选中

## UpCloud
- URL: `https://<account>.<region>.upcloudobjects.com`（他们会提供给您多个URL，遵循此模式的URL应该可以工作。）
- 区域：必填
- 强制路径样式：不选中

## Tebi
- URL: `https://s3.tebi.io`（这是Tebi提供的端点URL）
- 区域：必填
- 强制路径样式：不选中
