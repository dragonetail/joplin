# 同步

Joplin 的目标之一是避免与任何特定公司或服务绑定，无论是 Evernote、Google 还是 Microsoft。因此，同步功能的设计不依赖于任何特定服务。大部分同步过程在抽象层面进行，而对外部服务（如 Nextcloud 或 Dropbox）的访问通过轻量级驱动程序完成。通过创建提供类文件系统接口的简单驱动程序，即具备读取、写入、删除和列出项目的能力，可以轻松支持新服务。在不同服务之间切换也很简单。

目前，同步可以与 Joplin Cloud、Nextcloud、S3、WebDAV、Dropbox、OneDrive 或本地文件系统一起使用。要启用同步，请按照以下说明操作。之后，应用程序将在后台运行时自动同步，或者您可以点击"同步"手动开始同步。当本地应用程序进行任何内容更改后，Joplin 将自动在后台进行同步。

如果已安装**终端客户端**，也可以通过在终端中输入 `joplin sync` 在用户界面之外进行同步。这可用于设置 cron 脚本以定期同步。例如，以下命令将每 30 分钟执行一次同步：

` */30 * * * * /path/to/joplin sync`
