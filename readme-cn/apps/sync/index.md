# 同步

Joplin的目标之一是避免被绑定到任何特定公司或服务，无论是Evernote、Google还是Microsoft。因此，同步功能设计时没有对任何特定服务的硬性依赖。大部分同步过程都在抽象层面完成，而对外部服务的访问，如Nextcloud或Dropbox，是通过轻量级驱动程序完成的。通过创建提供类文件系统接口的简单驱动程序，即读取、写入、删除和列出项目的能力，可以很容易地支持新服务。从一个服务切换到另一个服务也很简单。

目前，可以与Joplin Cloud、Nextcloud、S3、WebDAV、Dropbox、OneDrive或本地文件系统进行同步。要启用同步，请按照以下说明操作。之后，应用程序将在运行时在后台同步，或者您可以点击"同步"手动启动同步。在本地应用程序上进行任何内容更改后，Joplin将自动在后台同步。

如果已安装**终端客户端**，也可以通过从终端输入`joplin sync`在用户界面之外进行同步。这可用于设置cron脚本定期同步。例如，这将每30分钟执行一次：

` */30 * * * * /path/to/joplin sync`
