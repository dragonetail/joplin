# 欢迎使用Joplin！

Joplin是一款免费、开源的笔记和待办事项应用程序，它可以帮助您编写和组织笔记，并在您的设备之间同步。笔记可以被搜索、复制、标记和修改，既可以直接通过应用程序操作，也可以使用您自己的文本编辑器。笔记采用[Markdown格式](https://joplinapp.org/help/apps/markdown)。Joplin提供**桌面版**、**移动版**和**终端版**应用程序。

本笔记本中的笔记概述了Joplin的功能和使用方法。通常，这三种应用程序大致共享相同的功能；任何差异将被明确标示。

![](./AllClients.png)

## Joplin分为三个部分

Joplin有三个主要列：

- **侧边栏**包含您的笔记本和标签列表，以及同步状态。

- **笔记列表**包含当前的笔记列表 - 可以是当前选定笔记本中的笔记、当前选定标签中的笔记，或者搜索结果。

- **笔记编辑器**是您编写笔记的地方。有一个**富文本编辑器**和一个**Markdown编辑器** - 点击右上角的**切换编辑器**按钮可以在两者之间切换！您也可以使用[外部编辑器](https://joplinapp.org/help/apps/external_text_editor)来编辑笔记。例如，您可以使用Typora作为外部编辑器，它将显示笔记以及任何嵌入的图像。

## 使用Markdown编写笔记

Markdown是一种轻量级标记语言，具有纯文本格式化语法。Joplin支持[Github风格的Markdown语法](https://joplinapp.org/help/apps/markdown)，并有一些变体和添加。

通常，虽然Markdown是一种标记语言，但它旨在便于人类阅读，即使未经渲染也是如此。这是一个简单的例子（您可以在查看器面板中看到它的外观）：

## 组织您的笔记

### 使用笔记本

Joplin笔记组织成笔记本和子笔记本的树状结构。

- 在**桌面版**上，您可以通过点击"新建笔记本"创建笔记本，然后可以通过将它们拖放到其他笔记本中或右键单击并选择"移动到笔记本"来随意组织它们。您也可以将子笔记本拖到"笔记本"标题以将其移动到根目录。
- 在**移动版**上，按下"+"图标并选择"新建笔记本"。
- 在**终端版**上，按`:mn`

![](./SubNotebooks.png)

### 使用标签

组织笔记的第二种方式是使用标签：

- 在**桌面版**上，右键单击笔记列表中的任何笔记，然后选择"标签"。您可以添加标签，用逗号分隔。
- 在**移动版**上，打开笔记并按下"⋮"按钮，然后选择"标签"。
- 在**终端版**上，输入`:help tag`查看可用命令。
