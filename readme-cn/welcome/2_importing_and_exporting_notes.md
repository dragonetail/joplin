# 导入和导出笔记

## 从Evernote导入

Joplin可以通过ENEX文件导入完整的Evernote笔记本，以及笔记、标签、图像、附件和笔记元数据（如作者、地理位置等）。

要导入Evernote数据，首先按照[这里](https://help.evernote.com/hc/en-us/articles/209005557-How-to-back-up-export-and-restore-import-notes-and-notebooks)的说明将您的Evernote笔记本导出为ENEX文件。然后，在**桌面版**上，执行以下操作：打开"文件">"导入">"ENEX"并选择您的文件。笔记将被导入到一个新的独立笔记本中。如果需要，可以将它们移动到不同的笔记本，或者重命名笔记本等。阅读[更多关于Evernote导入的信息](https://joplinapp.org/help/apps/import_export#importing-from-evernote)。

# 从其他应用程序导入

Joplin还可以从[许多其他应用程序](https://joplinapp.org/help/apps/import_export#importing-from-other-applications)导入笔记，以及从[Markdown或文本文件](https://joplinapp.org/help/apps/import_export#importing-from-markdown-files)导入。

# 导出笔记

Joplin可以导出为JEX格式（Joplin导出文件），这是一个可以包含多个笔记、笔记本等的归档文件。这种格式主要用于备份目的。您也可以导出为其他格式，如纯Markdown文件、JSON或PDF。在官方网站上了解[更多关于导出笔记的信息](https://joplinapp.org/help/apps/import_export#exporting)。
