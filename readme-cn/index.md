# Joplin 是什么？

<img width="64" src="https://raw.githubusercontent.com/laurent22/joplin/dev/Assets/LinuxIcons/256x256.png" align="left" style="margin-right:15px"/>

**Joplin** 是一款免费、开源的笔记和待办事项应用程序，可以处理大量组织到笔记本中的笔记。这些笔记可搜索、可复制、可标记和修改，既可以直接通过应用程序，也可以通过您自己的文本编辑器进行修改。笔记采用 [Markdown 格式](https://github.com/laurent22/joplin/blob/dev/readme/apps/markdown.md)。

从 Evernote 导出的笔记[可以导入](https://github.com/laurent22/joplin/blob/dev/readme/apps/import_export.md)到 Joplin 中，包括格式化内容（转换为 Markdown）、资源（图片、附件等）和完整的元数据（地理位置、更新时间、创建时间等）。纯 Markdown 文件也可以导入。

Joplin 是"离线优先"的，这意味着您的所有数据始终都在您的手机或电脑上。无论您是否有互联网连接，这确保了您的笔记始终可访问。

笔记可以使用[端到端加密](https://github.com/laurent22/joplin/blob/dev/readme/apps/sync/e2ee.md)安全地[同步](https://github.com/laurent22/joplin/blob/dev/readme/apps/sync/index.md)到各种云服务，包括 Nextcloud、Dropbox、OneDrive 和 [Joplin Cloud](https://joplinapp.org/plans/)。

所有平台上都提供全文搜索功能，以快速找到您需要的信息。应用程序可以使用插件和主题进行自定义，您也可以轻松创建自己的插件和主题。

该应用程序适用于 Windows、Linux、macOS、Android 和 iOS。同时，还有一个[网页剪藏器](https://github.com/laurent22/joplin/blob/dev/readme/apps/clipper.md)，用于保存网页和浏览器中的截图，适用于 [Firefox](https://addons.mozilla.org/firefox/addon/joplin-web-clipper/) 和 [Chrome](https://chrome.google.com/webstore/detail/joplin-web-clipper/alofnhikmmkdbbbgpnglcpdollgjjfek?hl=en-GB)。
